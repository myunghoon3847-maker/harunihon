하루니혼 Lite v1.0.0 안정화판

구성
- 히라가나·가타카나 및 음성
- 기초단어/표현 1000개
- 생활회화 100문장
- 즐겨찾기·암기완료
- 단어/회화 플래시카드
- 단어/회화 퀴즈와 오답노트
- 오늘 학습량·다크모드·글자 크게 보기
- PWA 설치 및 오프라인 캐시

배포
ZIP을 풀어 Netlify, GitHub Pages 등 HTTPS 호스팅에 업로드하세요.
스마트폰 Chrome 또는 삼성 인터넷에서 접속한 뒤 앱 설치/홈 화면 추가를 선택합니다.

주의
학습 기록은 해당 브라우저의 localStorage에 저장됩니다. 브라우저 데이터 삭제 시 초기화됩니다.
일본어 음성은 기기의 일본어 TTS 지원 여부에 따라 달라질 수 있습니다.

업데이트 v1.0.1: 단어·회화·플래시카드·문자표에 한국어 발음 표기를 추가했습니다. 한국어 발음은 초보자를 위한 근사 표기입니다.
